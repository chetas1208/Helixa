# V10 environment registry

Presets `temperate-forest-example`, `arid-example`, and `cold-alpine-example` are local assumed numbers. `NASA_POWER_ENABLED` is false. No climatology request is made.

`temperature_c`, `precipitation_mm_year`, `altitude_m`, and `recombination_rate` are `NOT_MODELED`. Changing temperature does not change the result hash.

`population_size`, `generation_time_years`, `horizon_years`, `selection_coefficient`, mutation, migration, initial frequency, and seed are Wright–Fisher inputs when the fitness class allows selection.
