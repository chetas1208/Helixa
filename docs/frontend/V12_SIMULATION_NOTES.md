## Built

### Evolution (`src/v12/evolution`)
- Two separate tracks in one read-only page, side drawer on the right (below on narrow screens).
  - **Genome version track** (`GenomeTrack.tsx`): baseline anchor, current marked, branch picker (only if >1 head), previous/next, scrub slider, stepper `<ol>` with `aria-current="step"`, `Compare baseline <-> current` DNA strip (`DiffStrip.tsx`, windowed reference vs edited bases, changed bases boxed + marker + aria-label, never colour alone), plain-language explanation (facts only, "in-silico", no trait/health claim). Baseline-only workspace: polished empty state, no invented ancestors.
  - **Agent harness track** (`HarnessTrack.tsx`): `/api/harnesses` via D's `useHarnesses`, lineage via `useHarnessLineage`. Rejected/failed statuses render with an X icon and text ("Rejected / failed"), never hidden. Policy/tool diff vs parent in the drawer.
  - **Link between tracks**: only when the workspace's recorded harness id (`/genome/workspaces/{id}/harness-lineage`) equals a `/api/harnesses` version id; otherwise the UI says "no recorded link" (true today: `harness-pche-baseline` vs `harness-v1`).
- Drawer (`EventDrawer.tsx`): What changed / Why / Source / Confidence and limitations / View evidence (revision ids, parent, `sequence_sha256` with Copy, edit_count) / Listen / expandable technical JSON. Every claim carries one `EvidenceBadge`.
- "Listen" calls the EXISTING `POST /api/voice/briefing` only if the harness step has a recorded receipt id (`metadata.receipt_id`); none exists today, so it is hidden with the reason. Genome revisions never have receipts, stated in the UI.
- Selecting an event publishes `useSession.selectedRevisionId` (+ `selectedPosition` of its first changed base); clicking a changed base in the strip sets `selectedPosition`; "Open in Genome Editor" switches tab.
- Data caveat handled: the live `GET /workspaces/{id}` has NO `revisions` array (types.ts comment was wrong). The timeline is built from `GET .../genome-lineage` (ids, parents, edit_count, sha256, `useGenomeLineage.ts`) plus the full `active_revision`. Edit lists for ANCESTORS of the active revision are the first `edit_count` entries of the active edit list (each commit appends exactly one edit; see store.py `commit`), flagged "derived". Revisions off the active line show edit counts only and "diff unavailable". A branched workspace (first revision already carries edits, parent in another workspace) gets a virtual "Reference baseline" anchor.
- Rejected / never-saved proposals are not stored by the backend; the UI says so instead of inventing steps.

### Earth Simulation (`src/v12/simulation`)
- Layout: left collapsible **Scenario** (draft), centre 3D Earth, right **Outcome**, bottom scrubber. Below 1024 px it stacks: scene, scrubber, scenario, outcome (page scrolls; canvas stays click-through).
- Scenario draft lives in `simulationStore.ts` (zustand, per workspace; survives tab switches, never persisted). Results are only ever backend frames; parameter edits cannot alter or delete a completed run.
- Horizon chips 10k/100k/500k/1M/2M + numeric; generation time is an explicit editable DECLARED ASSUMPTION with live hint `min generation time = horizon / 2000` (2M y => >= 1000 y/gen), a "Set to minimum" button, and a warning. Run stays enabled when over budget so the backend 409 text is surfaced verbatim.
- Parameters from `useParameterSpecs`: ACTIVE_MODELED => "Supported (wired to model)" with sliders + numeric inputs; NOT_MODELED => "Exploratory / not supported: does not change allele counts" (temperature, precipitation sent as context; elevation and recombination are not sent). Presets from `useEnvironmentPresets` labelled fictional/educational with their source text. Extra request fields without catalog entries (migrant frequency, fitness class) are labelled as request fields.
- Lifecycle idle/pending/complete/failed. No fake ETA; "Replicate i of N" is the only progress. Replicates = N sequential requests, seeds `seed..seed+N-1` (client-orchestrated, labelled). Idempotency-Key = `v12-<hash(revision id + canonical request)>` (`scenario.ts`).
- Runs: remembered ids via D's `recallSimulations` (newest first); results refetched by id with workspace check. Run A selector (drives playback + 3D), Run B compare, replicate min/max band drawn only when >= 2 real runs of the same scenario with identical frame grids.
- Outcome: SVG step chart (recorded frames hold until the next frame; no implied interpolation), legend for >= 2 series + direct end labels, validated colours (blue/orange/aqua dark steps, `dataviz` validator PASS) with dash as secondary encoding, extinction band + label, hover tooltip + keyboard arrows, Chart/Table toggle, playhead. Engine/fidelity/seed/result_sha256/limitations/narrative shown verbatim as text. CSV/JSON export of real frames only.
- Playback (`playbackClock.ts`): `visibleYear(elapsedS, playbackS, horizonYears, startYear=0)`, `elapsedForYear`, `frameIndexAt`/`frameAt` (latest frame at or before the year; interpolation only when `{interpolate:true}`, allele frequency only, flagged), `PlaybackController` (play/pause/toggle/restart/seek/speed x0.25..4, rAF driver with injectable `now`/`schedule`, wall-clock suspend on hidden tab). `usePlayback.ts` throttles React state (~15 Hz) and writes the mutable `liveClock` read by the scene.
- Scene (`EarthScene.tsx`, `earthSceneStore.ts`): procedural GLSL Earth + atmosphere + deterministic star field + instanced 120-segment ribbon. Lit share = current recorded frame's allele frequency, segment height = population size (taller = focal allele), extinct = flat grey and dimmed Earth. Matrices rewritten only when the recorded frame index changes; no per-frame setState; reduced motion stops rotation/damping and cuts stars. Climate inputs only drive a non-scientific lighting preview (warmth/cloud cover). Labelled "Illustrative visualization of model output".
- Engine unreachable: "Simulation engine not reachable" + `StaticExample.tsx`, clearly marked "Static explanatory example. Not live. Not computed by this app." (hand-written curves).
- Frame ownership: `checkRunOwnership` (simulation_id + workspace_id) gates every display; runs from an earlier genome revision are labelled.
