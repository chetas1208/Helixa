# V12 data layer, state sync and Harness Library (Agent D)

## Built
- **Validated API layer** (`apps/web/src/v12/api/`)
  - `schemas.ts`: zod schemas for every wire type; each `satisfies z.ZodType<T>` for the type in `types.ts`. Extra fields are tolerated (stripped; harness records passthrough). Also `HarnessLineage`, `LineageResult`, `HealthResponse`, `WorkspaceCapabilities`.
  - `client.ts`: `apiGetParsed/apiPostParsed/apiPatchParsed` (validate before returning), 30 s timeout merged with the caller's `AbortSignal`, typed `ApiError` (`.conflict` for 409 with the server detail, `.notFound`, `.network`, `.unavailable`, `.contractMismatch`). A body that fails validation (or is not JSON) raises `ApiError(502, "Response did not match the expected contract", path, issues[])`. `shouldRetryRequest`: only network/5xx, max 2, never 4xx/409/contract errors. Legacy `apiGet/apiPost` are kept (unvalidated; do not use for render state).
  - `hooks.ts`: all frozen hooks keep their signatures (`useSimulation(id, workspaceId?)` gained an optional 2nd arg). Per-workspace reads assert `body.workspace_id === requested id` (else contract error). New: `useHarnesses`, `useHarnessLineage(id)` (404 -> `{recorded:false, reason}`), `useHealth` (polls `/api/health`, writes `session.connection`), `useTranscriptionAvailability` (POST probe of `/api/voice/transcribe` with an empty body: 404/405/501 -> `{available:false, reason}`; today the route is absent), `useRememberedSimulations`, `useWorkspaceCapabilities` (side-effect-free probes against a non-existent workspace id: rename, archive, server-side simulation list), `useListedSimulations`, `useRenameWorkspace`, `useArchiveWorkspace`. `useRunSimulation` remembers the new id itself and seeds the cache.
  - `queryClient.ts`: `createQueryClient()` (staleTime 5 s, gc 5 min, focus/reconnect refetch, retry policy above, mutations never retry).
  - `queryKeys.ts`: `qk` (workspace id in every per-workspace key), `workspaceIdFromKey`, `isStaleKeyForWorkspace`.
  - `simMemory.ts`: `rememberSimulation/recallSimulations` (localStorage ids only, newest first, cap 20, validated, try/catch, injectable storage).
  - `connection.ts`: `connectionFromHealth`; `capabilities.ts`: `routeExists`.
- **State** (`state/`): `urlSync.ts` (`useUrlSync()` -> `{status, notice, retry}`), `urlParams.ts` (pure parse/serialise/bootstrap/history-mode), `raceGuard.ts` (latest-wins gate, serial queue, `onlyIfActive`).
  - Bootstrap: URL workspace if it exists, else server `active`, else first non-archived, else null. Bad/unknown params are ignored and the URL is normalised with `replaceState`; user tab/workspace changes use `pushState`; popstate restores the tab and switches workspace through the guard (a refusal rewrites the URL back). Only `tab` and `workspace` ids reach the URL. On any active-workspace change, queries of other workspaces are cancelled (`cancelQueries`). Bootstrap does not call `select` (a deep link does not mutate server state).
- **Switch guard** (`library/SwitchGuard.tsx`, `library/switchFlow.ts`): `useGuardedWorkspaceSwitch()` and `<SwitchGuardDialog/>` (Radix, focus trapped, Escape = cancel). Save draft = propose+commit sequentially against the draft's own workspace (first op `baseCounter`, then the counter each commit returns); the first 409/REJECTED/error stops, shows the server text, writes the unsaved remainder back rebased, and does not switch. Then fresh list -> `select(expected_counter)` -> `setActiveWorkspaceId`. Latest switch wins: a new switch closes the prompt, aborts the older select, and selects are serialised. If no dialog is mounted, a switch away from a draft is refused (fail-safe, `useSwitchGuardStore.lastError`).
- **Harness Library** (`library/`): `HarnessLibraryTab` (subtitle "Saved workspaces: a genome state plus its analysis harness, evidence and simulations"), `WorkspaceCard`, `WorkspaceDrawer`, `CompareDialog` (read-only edit diff), `NameDialog` (create/branch/rename), `ConfirmDialog` (archive), `SimulationRuns`, `libraryModel.ts` (pure). Pinned immutable baseline panel (fork = Branch). Search, filter (all/edited/baseline-only/show archived), sort (updated, genome-revision created, name, edit count). Export provenance = client-side JSON of ids, hashes, edits, branch path, run ids (no sequence windows, no transcripts). Rename/Archive are enabled only when the capability probe finds the route (it does on the current backend; Archive is refused for the active workspace); Duplicate is always disabled with an endpoint-citing tooltip (no route; Branch is the fork). Archived workspaces are hidden by default and cannot be activated. The "created" sort uses the active revision's time because `GET /workspaces` has no `created_at`.
- Evidence badge per workspace: no edits = REFERENCE; edits whose allele at commit matches the replayed history = HYPOTHESIS ("In-silico edit", not lab-verified); inconsistent record = INCONCLUSIVE. Runs = SIMULATED.
