## 1. The Core Scientific Boundary

The defining foundation of DIAMOND Genome V15 is **a defensible causal boundary** between:
1. A DNA sequence edit.
2. Its molecular biological consequences (transcripts, residues).
3. Associated tissue expression.
4. Hypothetical phenotype scenarios.
5. Simulated forward-time population allele trajectories.
6. 3D cinematic rendering.

No language model and no rendering pipeline may silently cross or blur that boundary.

---

## 2. The 7-Tier Gene-to-Body Evidence Ladder

Every output claim and annotation in DIAMOND Genome must be classified into one of seven formal tiers:

| Tier | Enum Tag | Description & Verification Criteria | Permitted Visualization |
|---|---|---|---|
| **Tier 1** | `SEQUENCE_VERIFIED` | Exact nucleotide substitution verified against pinned GRCh38 FASTA slice checksums. | Highlighted base change in 3D DNA sequence strip; ring flash. |
| **Tier 2** | `TRANSCRIPT_COMPUTED` | Exon, splice, codon, and transcript consequences computed via Ensembl VEP or pinned annotations. | Transcript ID annotation, consequence tag (e.g. missense). |
| **Tier 3** | `PROTEIN_ANNOTATED` | Amino acid alteration mapped to known protein residue or structure (e.g., Mol* / PDB). | Residue mapping card; structural annotation. |
| **Tier 4** | `EXPRESSION_ASSOCIATION` | Gene reported expressed or regulated in an anatomical tissue (GTEx / HPA / Bgee). | Soft tissue glow on anatomical silhouette with caveat: *"Expression association is not demonstrated causation."* |
| **Tier 5** | `PHENOTYPE_ASSOCIATION` | Curated literature / population-level association (GWAS Catalog v2, HPO). | Literature association badge with study context and effect size. |
| **Tier 6** | `CAUSAL_MODEL_ASSUMED` | Deliberately parameterized hypothetical trait and body-morph scenario with explicit limits. | Bounded mesh adjustment labeled *"Hypothetical Trait Model"* with uncertainty band. |
| **Tier 7** | `UNSUPPORTED` | No defensible molecular or body inference. | Constant neutral baseline anatomy with explicit tag: *"A body-shape effect cannot be inferred from this edit."* |

## 3. Mandatory Rules on Body Geometry and Morphs

1. **Expression Is Not Causality:** A gene expressed in the heart is not a "heart controlling gene" and does not cause a deformed heart mesh.
2. **Never Synthesize Anatomy from LLM Text:** An LLM narrative cannot invent morph target weights. Only an explicit, mathematically calibrated trait model can drive mesh adjustments.
3. **Neutral Baseline Guarantee:** When an edit has no validated trait model, the 3D body figure retains neutral anatomical proportions. The anatomical region receives an evidence marker and an honest explanation. This is a scientifically correct and required outcome.
4. **Honest Copy Requirement:** The caption *"Illustrative figure... No validated body-level effect"* must be visible whenever hypothetical rendering is displayed.
